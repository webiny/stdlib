# @webiny/utils-browser

Browser utilities built on constructor injection. Depends on `@webiny/utils-common`.

## Installation

```sh
npm install @webiny/utils-browser
```

## Features

| Feature                                                       | Description                                                                     |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [LocalStorageCache](src/features/LocalStorageCache/README.md) | `Cache` implementation backed by `window.localStorage` — never throws, SSR-safe |
